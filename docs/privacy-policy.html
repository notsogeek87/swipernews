Politique de confidentialité — SwiperNews

Dernière mise à jour : 17 août 2026

Résumé

SwiperNews ne collecte aucune donnée personnelle. L'application respecte votre vie privée.

Principes fondamentaux

  • ✅ Pas de compte : aucune inscription requise
  • ✅ Pas de suivi : aucune télémétrie, aucun analytics
  • ✅ Pas d'algorithme : le fil affiche exactement les sources que vous avez choisies
  • ✅ Pas de recommandations : les articles Wikipédia sont tirés au hasard, jamais recommandés
  • ✅ Données locales uniquement : tout se stocke sur votre appareil

Données collectées

Sur la version mobile (APK Android)
Aucune donnée n'est envoyée en dehors de votre appareil, sauf :

  • Flux RSS : vos sources choisies sont interrogées directement depuis votre appareil
  • Wikipédia : les catégories de centres d'intérêt sont interrogées en direct (pas de compte créé)
  • Images d'articles : chargées depuis les serveurs des éditeurs respectifs (pas sous notre contrôle)

Sur la version web (PWA)
Mêmes principes. Les flux RSS passent par nos serveurs Vercel uniquement pour contourner les restrictions CORS des navigateurs (une limite technique, pas un choix de design). Aucune donnée n'est conservée.

Données stockées localement

L'application stocke sur votre appareil uniquement :

  • Vos sources RSS importées/exportées (format OPML standard)
  • Vos préférences (langue, dose d'apprentissage, filtres)
  • L'historique local du fil (articles affichés lors de la dernière session)
  • Vos réglages du lecteur (taille de police, thème)

Aucune de ces données n'est synchronisée, envoyée ailleurs, ni vendue.

Tiers services

L'application ne contacte aucun service publicitaire ni d'analyse. Elle interroge uniquement :

  • Vos sources RSS : domaines que vous avez explicitement cochées (y compris des chaînes YouTube ajoutées comme flux Shorts)
  • Wikipédia : API publique Wikipédia (domaine public)
  • Images d'articles : serveurs d'éditeurs (Open Graph, contrôlés par chaque média)

Aucun tracker, aucun pixel, aucune publicité.

Suppression de données

Comme aucune donnée n'est collectée en ligne, il n'y a rien à demander de supprimer. Désinstaller l'application efface tout le stockage local.

Droit d'accès et contrôle

Vous gardez un contrôle total sur vos données :

  • Export : vos sources s'exportent en OPML standard à tout moment
  • Suppression : supprimez une source = elle arrête d'être interrogée immédiatement
  • Indépendance : l'application fonctionne hors-ligne une fois chargée

Sécurité

  • HTTPS : les flux RSS sont chargés en HTTPS (sur le web)
  • Pas de compte = pas de mot de passe à protéger
  • Code ouvert : dépôt GitHub — vérifiez-le vous-même

Modifications de cette politique

Tout changement sera annoncé dans les notes de version de l'application. Cette politique peut être mise à jour à tout moment.
